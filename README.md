# Discord Razorpay Subscription Bot

Production-ready Discord bot with:
- Razorpay payments
- Subscription roles
- Auto expiry & reminders
- Ticket system
- Admin commands
- Dashboard & logs
- SQLite persistence
- bot-hosting.net compatible

---

## Requirements
- Node.js 18+
- Discord Bot Token
- Razorpay Account
